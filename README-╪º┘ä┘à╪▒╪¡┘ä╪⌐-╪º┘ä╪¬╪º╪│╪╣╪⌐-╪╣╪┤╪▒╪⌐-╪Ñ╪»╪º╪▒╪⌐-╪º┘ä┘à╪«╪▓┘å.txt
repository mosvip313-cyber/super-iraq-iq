سوبر العراق IQ — المرحلة 19: إدارة المخزن والتقارير

المزايا:
- صفحة مخزن مستقلة تعرض الأصناف، قيمة المخزون بسعر التكلفة، الأصناف النافدة وقريبة النفاذ.
- حالة المخزون تعتمد على الرصيد وحد التنبيه minStock لكل منتج، والافتراضي 5 وحدات.
- تنبيهات داخل البرنامج مع عدد الأصناف المتأثرة في القائمة الجانبية.
- تقرير أرصدة قابل للبحث والتصفية حسب الحالة والفئة، مع تصدير Excel وطباعة.
- تقرير حركات المخزون مع نطاق تاريخ ونوع حركة، ومجاميع الكميات الداخلة والخارجة.
- المبيعات تخصم المخزون وتسجل حركة خروج برقم الفاتورة، والمشتريات والمرتجعات تسجل حركة دخول وفق العمليات الحالية.
- تنبيه بعد البيع عند نفاد الصنف أو وصوله إلى حد التنبيه.

ملاحظات:
- قيمة المخزون تقديرية باستخدام تكلفة الوحدة الحالية المسجلة لكل منتج.
- تقرير الحركات يعرض الحركات المسجلة منذ تفعيل سجل الحركة؛ لا يتم تخمين حركات قديمة غير موجودة بالسجل.
- لم تُنفذ بعد إدارة مواقع ورفوف ومستودعات متعددة أو جرد دوري بموافقات وصلاحيات متقدمة.
- تم فحص صياغة JavaScript وسلامة أرشيف ZIP، ولم يُجر اختبار شامل داخل متصفح فعلي.

المرحلة العاشرة — الربط السحابي والذكاء الاصطناعي
==================================================

تحتوي الحزمة على واجهة ربط سحابي، وخادم API يستخدم OpenAI Responses API، ومخطط PostgreSQL/Supabase لحفظ لقطة بيانات كل فرع، ومحاولة مزامنة عند عودة الإنترنت. تبقى البيانات المحلية متاحة عند انقطاع الاتصال.

التشغيل المحلي: اضغط مرتين على تشغيل-سوبر-العراق.bat.
إعداد الخادم: للمسؤول الفني فقط، استخدم إعداد-الخادم-للمسؤول.bat واقرأ دليل-التسليم-للزبون.txt.

تنبيه: هذه الحزمة هي تجهيز برمجي وليست خدمة سحابية منشورة. تتطلب حسابات ومفاتيح يملكها صاحب النظام، واستضافة HTTPS، واختباراً ميدانياً قبل تسليمها كنظام إنتاجي. لا تُدخل مفاتيح سرية في واجهة المتصفح.

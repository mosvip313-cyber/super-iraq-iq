سوبر العراق IQ — المرحلة الثالثة: إعدادات البرنامج

الأقسام:
- إعدادات البرنامج: العملة واللغة كتفضيلات محفوظة.
- بيانات المتجر: الاسم، الهاتف، العنوان، الرقم الضريبي.
- طباعة الفواتير: حجم الورق 58mm / 80mm / A4، تذييل الفاتورة ومعاينة الطباعة.
- طباعة الباركود: عرض وارتفاع الملصق، عدد النسخ، وبادئة اختيارية، مع تجهيز ملصقات للمنتجات ذات الباركود.
- النسخ الاحتياطي: تنزيل JSON واستعادة نسخة بعد تأكيد المستخدم.
- عن البرنامج: الإصدار وطريقة التخزين وحدود النسخة التجريبية.

التشغيل: فك ضغط ZIP وافتح apps/admin-web/index.html في Chrome أو Edge.
مهم: البيانات ما زالت محفوظة محلياً بالمتصفح. طباعة الباركود المولدة في هذه النسخة هي رسمة أولية وليست معيار باركود معتمداً لجميع أجهزة المسح؛ يلزم اختبارها وتطويرها قبل الاستخدام التجاري. الطباعة تفتح نافذة طباعة المتصفح، ولا يوجد تكامل مباشر مع الطابعة. النسخ الاحتياطي يدوي وليس سحابياً.

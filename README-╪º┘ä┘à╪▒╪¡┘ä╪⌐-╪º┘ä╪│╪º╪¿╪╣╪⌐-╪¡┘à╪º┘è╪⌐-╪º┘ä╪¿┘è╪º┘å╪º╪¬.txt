سوبر العراق IQ — المرحلة السابعة: حماية البيانات

التحديثات:
- حفظ كلمات المرور الجديدة باستخدام PBKDF2 مع SHA-256 وملح عشوائي عند توفر Web Crypto.
- ترقية الحسابات القديمة إلى صيغة التجزئة الجديدة عند تسجيل دخول صحيح.
- إيقاف محاولات تسجيل الدخول دقيقة واحدة بعد 5 محاولات فاشلة متتالية.
- تحسين التحقق من بنية النسخة الاحتياطية قبل استبدال البيانات، وإضافة قيم افتراضية للحقول الاختيارية.
- الحفاظ على معلومات المطور: Mohammad Saleem، واتساب 07713541234.

التشغيل:
1. فك ضغط الملف.
2. افتح apps/admin-web/index.html في متصفح حديث.
3. إذا كان لديك حساب سابق، سجّل الدخول بالطريقة المعتادة؛ عند نجاح الدخول ستتم ترقية تجزئة كلمة المرور تلقائياً.
4. إذا لم تنشئ حساباً، أكمل التفعيل ثم أنشئ حساب المدير.

حدود مهمة:
- هذه نسخة تجريبية تعتمد localStorage، وليست قاعدة بيانات SQLite.
- التفعيل محلي ومفتاحه موجود في كود الواجهة؛ لا يعتبر حماية ترخيص تجارية.
- قفل المحاولات محلي ويمكن تجاوزه من شخص لديه وصول مباشر إلى بيانات المتصفح.
- لم تُنفذ بعد مزامنة سحابية فعلية بين الفروع.
- لا تحفظ كلمات المرور الحقيقية في ملفات أو ترسلها لأي شخص.

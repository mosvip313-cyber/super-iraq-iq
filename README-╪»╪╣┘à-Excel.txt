تحديث دعم Excel - سوبر العراق IQ

- تصدير المنتجات والفواتير والمشتريات والمصاريف والمرتجعات والعملاء والموردين والمستخدمين وحركات المخزون إلى ملفات XLS متوافقة مع Microsoft Excel.
- قسم النسخ الاحتياطي يحتوي زر لتصدير بيانات كل الأقسام التي تحتوي على بيانات، كل قسم بملف Excel مستقل.
- استيراد المنتجات يدعم CSV وملفات XLS المحفوظة كجدول HTML من Excel، ويحدّث المنتج الموجود عند تطابق الباركود.
- الاستيراد الحالي مخصص لقائمة المنتجات فقط. ملفات XLSX الحديثة ليست مدعومة مباشرة دون مكتبة إضافية؛ احفظها من Excel بصيغة XLS أو CSV قبل الاستيراد.
- النسخة الاحتياطية الكاملة والاستعادة تبقيان بصيغة JSON، لأنهما تحفظان العلاقات والإعدادات وبيانات التطبيق كاملة.
- تصدير Excel لا يغيّر بيانات النظام، وتصدير كل الأقسام ينزّل ملفاً منفصلاً لكل قسم يحتوي على بيانات.

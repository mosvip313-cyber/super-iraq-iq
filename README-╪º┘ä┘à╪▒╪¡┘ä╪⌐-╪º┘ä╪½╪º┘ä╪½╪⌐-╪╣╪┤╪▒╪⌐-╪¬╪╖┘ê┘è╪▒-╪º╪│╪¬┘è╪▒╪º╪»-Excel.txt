سوبر العراق IQ — المرحلة 13: تطوير استيراد Excel

الإضافات:
- قوالب Excel جاهزة للاستيراد لأقسام المنتجات والعملاء والموردين والمصاريف.
- استيراد العملاء مع تحديث سجل العميل عند تطابق رقم الهاتف.
- استيراد الموردين مع تحديث سجل المورد عند تطابق رقم الهاتف.
- استيراد المصاريف من قالب القسم، مع حفظ المبلغ والتصنيف وطريقة الدفع والملاحظات.
- حدود لحجم ملفات الاستيراد ومعالجة أخطاء القراءة برسائل واضحة.
- الإبقاء على تصدير البيانات والنسخ الاحتياطي الكامل بصيغة JSON.

طريقة الاستخدام:
1. افتح القسم المطلوب واضغط «قالب Excel».
2. افتح القالب ببرنامج Excel، واحذف صف المثال وأدخل البيانات.
3. احفظ الملف بصيغة XLS المتوافقة أو CSV بترميز UTF-8.
4. اضغط «استيراد» واختر الملف.

ملاحظات مهمة:
- هذه النسخة تقرأ CSV وملفات Excel القديمة بصيغة HTML/XLS التي ينتجها التطبيق، ولا تتضمن بعد محلل XLSX أصلي لملفات .xlsx الحديثة.
- لا تستورد أرصدة العملاء يدوياً من القالب؛ الرصيد يبدأ بصفر ويُحتسب من عمليات البرنامج.
- الاستيراد يضيف/يحدّث سجلات الدليل ولا يستبدل قاعدة البيانات كاملة.
- تم فحص صياغة JavaScript وسلامة أرشيف ZIP، ولم يجر اختبار متصفح شامل أو اختبار ميداني لكل إصدارات Excel.

سوبر العراق IQ — المرحلة الثانية (نموذج أولي)

الإضافات:
- حد تنبيه لكل منتج عند انخفاض المخزون.
- تنبيه بصري في جدول المنتجات عند انخفاض الكمية.
- شاشة حركة المخزون: إدخال، إخراج، أو تسوية إلى كمية محددة.
- تسجيل حركات الصرف الناتجة عن فواتير البيع.
- منع إضافة كمية إلى السلة أكبر من المخزون المتوفر.
- تبقى البيانات محفوظة محلياً في المتصفح (localStorage).

التشغيل:
1) فك ضغط الملف.
2) افتح apps/admin-web/index.html بواسطة Chrome أو Edge.

تنبيه:
هذه نسخة تجريبية وليست نظاماً جاهزاً للإنتاج. لا توجد بعد قاعدة بيانات SQLite أو صلاحيات مستخدمين فعلية أو مزامنة بين الفروع أو طباعة فواتير حقيقية. قبل استخدامها تجارياً يجب نقل التخزين إلى قاعدة بيانات محلية واختبار النسخ الاحتياطي والمبيعات والمرتجعات.

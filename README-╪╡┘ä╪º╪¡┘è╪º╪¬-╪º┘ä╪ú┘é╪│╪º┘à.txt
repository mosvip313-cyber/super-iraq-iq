سوبر العراق IQ — تحديث صلاحيات الأقسام

التحديث:
- حسابات الموظفين يمكنها تسجيل الدخول باسم المستخدم وكلمة المرور.
- عند إضافة مستخدم، يحدد المسؤول الدور وكلمة المرور والأقسام المسموحة.
- مفاتيح الأقسام: dashboard, pos, products, warehouse, customers, suppliers, purchases, expenses, returns, cashbox, accounting, reports, users, settings
- من صفحة المستخدمين يمكن تعديل صلاحيات كل موظف، إيقافه أو حذفه.
- إخفاء أقسام القائمة ومنع التنقل إليها عند عدم امتلاك الصلاحية.
- كلمة مرور الموظف تحفظ كـ hash باستخدام PBKDF2-SHA256 عند توفر Web Crypto.
- المدير الرئيسي له صلاحية جميع الأقسام.

طريقة الاستخدام:
1. استخرج ملف ZIP كاملاً.
2. افتح البرنامج وسجل دخول المدير.
3. افتح المستخدمين ثم + إضافة مستخدم.
4. أدخل اسم المستخدم وكلمة المرور (8 أحرف على الأقل) والدور.
5. أدخل مفاتيح الأقسام المسموحة مفصولة بفواصل إن أردت تخصيص الصلاحيات؛ إذا تركتها فارغة يتم استخدام صلاحيات الدور الافتراضية.
6. سجل خروج ثم ادخل بحساب الموظف لاختبار الأقسام.
7. من زر «صلاحيات الأقسام» يمكن تعديل مفاتيح الأقسام المسموحة لاحقاً.

ملاحظة أمنية:
هذا إصدار محلي يعمل داخل المتصفح، والبيانات والصلاحيات تحفظ محلياً على الجهاز. لا تعتبر هذه الصلاحيات بديلاً عن مصادقة وصلاحيات خادمية في نظام متعدد الفروع أو عند استخدام أجهزة غير موثوقة. خذ نسخة احتياطية قبل التحديث.

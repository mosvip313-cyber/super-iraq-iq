المرحلة 34 — ترتيب واجهة الكاشير

- نقل لوحة العميل وخيارات البيع والعملة والدفع والخصم والإجماليات وزر إتمام البيع إلى المساحة الواسعة أسفل/بجوار قائمة المنتجات على الشاشات الكبيرة.
- إبقاء سلة المشتريات وعناصرها في اللوحة الجانبية لتكون مرئية بشكل مستقل.
- إعادة لوحة إتمام البيع إلى أسفل السلة على الشاشات الصغيرة لتجنب ضغط العرض.
- لم تتغير دوال الحساب أو حفظ الفاتورة؛ التعديل يخص ترتيب الواجهة فقط.

التحقق: فحص صياغة JavaScript وملف ZIP. يلزم اختبار بصري داخل المتصفح على مقاسات شاشة مختلفة قبل اعتمادها للاستخدام اليومي.

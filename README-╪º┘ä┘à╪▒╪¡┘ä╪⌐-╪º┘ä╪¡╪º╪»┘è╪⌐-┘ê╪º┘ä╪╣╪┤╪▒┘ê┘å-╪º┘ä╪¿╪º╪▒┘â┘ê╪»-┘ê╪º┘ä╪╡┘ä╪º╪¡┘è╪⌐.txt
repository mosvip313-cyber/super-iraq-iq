سوبر العراق IQ — المرحلة 21: الباركود والصلاحية ووحدات القياس

الإضافات:
- حقول بطاقة المنتج: وحدة القياس، عدد الوحدات بالكارتون، رقم الدفعة/التشغيلة، وتاريخ انتهاء الصلاحية.
- تقرير داخل المخزن يعرض المواد المسجل لها تاريخ صلاحية، والمواد المنتهية أو التي تنتهي خلال 30 يوماً.
- تصدير تقرير الصلاحية إلى ملف متوافق مع Excel.
- إضافة الوحدة والدفعة وتاريخ الانتهاء إلى تقرير المخزن.
- الإبقاء على بحث الباركود الحالي والبيع عبر واجهة نقطة البيع.

ملاحظات مهمة:
- إدارة الصلاحية هنا على مستوى بطاقة المنتج (تاريخ واحد لكل منتج)، وليست نظام دفعات متعددة مستقل؛ إذا كانت للمادة عدة دفعات بتواريخ مختلفة، أنشئ سجلات/منتجات منفصلة مؤقتاً أو لا تعتمد على هذا التقرير لتحديد الدفعة التي يجب صرفها.
- حقل عدد الوحدات بالكارتون للتوثيق حالياً، ولا يجري تحويل الكميات تلقائياً بين الحبة والكارتون في البيع أو الشراء.
- ملفات Excel تصدير بصيغة XLS/HTML متوافقة؛ استيراد XLSX مباشرة غير مدعوم.
- اجتاز JavaScript فحص الصياغة وZIP فحص السلامة؛ لم يجر اختبار شامل داخل المتصفح أو مع قارئ باركود مادي.

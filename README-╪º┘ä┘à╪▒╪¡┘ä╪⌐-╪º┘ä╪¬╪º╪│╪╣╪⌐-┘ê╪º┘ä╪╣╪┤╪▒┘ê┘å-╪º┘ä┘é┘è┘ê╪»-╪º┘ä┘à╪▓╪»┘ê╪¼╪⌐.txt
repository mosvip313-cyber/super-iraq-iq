المرحلة 29 — القيود اليومية المزدوجة

الجديد:
- قسم القيود اليومية داخل صفحة «المحاسبة والتحصيل والورديات».
- إدخال تاريخ وبيان وحساب مدين وحساب دائن ومبلغ.
- منع حفظ القيد إذا كانت البيانات ناقصة أو الحسابان متطابقين أو المبلغ غير صحيح.
- كل قيد محفوظ يحمل مبلغاً واحداً للمدين ومبلغاً مساوياً للدائن.
- عرض القيود اليدوية وملخص إجمالي المدين والدائن وفرق الميزان.
- ميزان مراجعة مبسط مجمع حسب الحسابات من القيود اليدوية فقط.
- تصدير القيود إلى CSV يفتح في Excel.
- البيانات تحفظ ضمن قاعدة بيانات المتصفح المحلية للتطبيق وتدخل ضمن النسخ الاحتياطية التي تعتمد على تصدير قاعدة البيانات.

مهم جداً — حدود المحاسبة:
- هذه قيود يدوية مستقلة؛ لا يتم إنشاء قيود تلقائية من المبيعات والمشتريات والمرتجعات أو المصاريف.
- ميزان المراجعة يعرض القيود اليدوية فقط، ولا يمثل كل عمليات المتجر تلقائياً.
- لا توجد حالياً عمليات تعديل/عكس/اعتماد للقيود، ولا إقفال فترة محاسبية.
- الحسابات والأسماء الافتراضية قائمة ثابتة قابلة للتوسعة لاحقاً.
- التخزين محلي في المتصفح وليس قاعدة محاسبية مركزية متعددة المستخدمين.
- اختبرنا صياغة JavaScript وفحص سلامة ZIP فقط؛ لم يتم اختبار التدفق على خادم إنتاج أو مراجعة محاسب قانوني.

طريقة الاستخدام:
1. افتح البرنامج وسجّل الدخول بمستخدم لديه صلاحية المحاسبة.
2. افتح «المحاسبة والورديات».
3. ضمن «القيود اليومية المزدوجة»، أدخل التاريخ والبيان والحساب المدين والدائن والمبلغ.
4. اضغط «حفظ القيد المتوازن».
5. راجع إجماليات المدين والدائن وميزان المراجعة، ويمكنك تصدير القيود CSV.

لا تعتمد القيود كتسجيل رسمي قبل مراجعتها من محاسب مختص وتهيئة دليل حسابات مناسب لنشاطك.

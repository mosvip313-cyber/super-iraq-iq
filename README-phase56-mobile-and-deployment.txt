سوبر العراق IQ — المرحلة 56: نسخة متجاوبة للموبايل وتجهيز الاستضافة

ما تغير:
- تحسين تخطيط الهاتف: شريط تنقل أفقي قابل للتمرير، حقول وأزرار مناسبة للمس، جداول قابلة للتمرير، ونوافذ ملائمة للشاشة الصغيرة.
- إضافة PWA manifest وأيقونات وService Worker لتثبيت التطبيق من المتصفح عند الاستضافة عبر HTTPS.
- لا يقوم Service Worker بتخزين /api أو بيانات API في الكاش؛ الكاش مخصص لملفات الواجهة فقط.
- يمكن تشغيل الواجهة وAPI من نفس الأصل/الرابط باستخدام Express.
- تعديل Dockerfile وdocker-compose ليضمنا ملفات الواجهة في صورة الخادم.
- عنوان API الافتراضي يصبح نفس عنوان الموقع المنشور، مع بقاء رمز الفرع مطلوباً للمزامنة.

تشغيل محلي:
1) ثبّت Node.js 20 أو أحدث.
2) انسخ server/.env.example إلى server/.env واضبط الأسرار.
3) من مجلد المشروع نفّذ: docker compose -f deployment/docker-compose.yml up --build -d
4) افتح http://localhost:8787 على الحاسبة.
5) لفتح الموقع من الموبايل على نفس شبكة Wi-Fi مؤقتاً: استخدم عنوان IP المحلي للحاسبة مع المنفذ 8787، بعد السماح للمنفذ في جدار الحماية. لا تستخدم هذه الطريقة كرابط عام للإنترنت.

النشر العام:
- انشر الخدمة على استضافة تدعم Node 20 أو Docker، ثم افتح HTTPS.
- اضبط متغيرات البيئة في لوحة الاستضافة ولا ترفع server/.env إلى Git.
- عيّن SUPABASE_URL وSUPABASE_SERVICE_ROLE_KEY وBRANCH_TOKENS_JSON وADMIN_DASHBOARD_TOKEN وINVENTORY_ADMIN_TOKEN حسب الحاجة، وكل الرموز سرية وعشوائية بطول 32 حرفاً على الأقل. على Render/Docker اضبط PUBLIC_HOST على اسم النطاق المنشور دون https://، وPUBLIC_SCHEME=https. يمكن أيضاً وضع رابط الواجهة الكامل في CORS_ORIGINS.
- نفّذ ملفات SQL الخاصة بالمراحل المطلوبة في Supabase قبل اختبار كل وظيفة.
- بعد النشر، افتح رابط HTTPS من الهاتف واختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إذا ظهر الخيار.

تنبيهات مهمة:
- هذه الحزمة لا تحتوي رابط استضافة عام جاهز؛ الرابط العام لا يتولد إلا بعد نشر الخدمة في حساب استضافة.
- لم يتم الاتصال بحساب استضافة أو Supabase من هذه البيئة، ولم يتم اختبار عدة فروع/أجهزة حقيقية.
- تخزين IndexedDB محلي لكل متصفح؛ مشاركة البيانات بين الأجهزة تعتمد على إعداد السحابة واختبار المزامنة.
- Service Worker لا يجعل المزامنة تعمل بلا إنترنت؛ يحافظ فقط على ملفات الواجهة الأساسية، وتبقى مزامنة البيانات معتمدة على الشبكة.
- قبل الاستخدام التجاري، اختبر البيع، المرتجعات، الطباعة، الصلاحيات، النسخ الاحتياطي، المزامنة والتعارضات على نسخة تجريبية.

سوبر العراق IQ — المرحلة 20: الجرد الذكي

المزايا:
- إنشاء محضر جرد بمعلومات الرصيد الدفتري وقت بدء المحضر.
- إدخال الكمية الفعلية لكل منتج وحفظ المحضر كمسودة.
- اعتماد الجرد بعد إدخال كميات صحيحة لكل الأصناف ومراجعة رسالة التأكيد.
- تسوية رصيد المنتجات إلى الكمية الفعلية عند الاعتماد، وإنشاء حركة مخزون من نوع تسوية لكل فرق غير صفري.
- سجل تدقيق يتضمن الرصيد السابق والجديد والفرق والسبب ورقم المحضر.
- إلغاء محضر المسودة دون تغيير المخزون.
- عرض المحاضر السابقة وتصدير تفاصيلها إلى ملف Excel متوافق بصيغة XLS.
- تضمين بيانات محاضر الجرد وسجل التدقيق في التصدير العام والنسخ الاحتياطي.

طريقة الاستخدام:
1. استخرج ملف ZIP بالكامل.
2. افتح مجلد super-iraq-iq-v1 وشغّل تشغيل-سوبر-العراق.bat أو افتح apps/admin-web/index.html.
3. انتقل إلى المخزن ثم اضغط بدء محضر جرد.
4. أدخل الكمية الفعلية لكل صنف، واحفظ المسودة عند الحاجة.
5. راجع الفروقات ثم اعتمد المحضر. الاعتماد يغير المخزون فعلياً ولا يمكن التراجع عنه تلقائياً؛ أنشئ نسخة احتياطية أولاً.

ملاحظات وحدود:
- الجرد محلي على قاعدة بيانات هذا الجهاز؛ المزامنة السحابية متعددة الفروع ليست مفعّلة تلقائياً.
- لا يوجد دعم بعد لعدة مستودعات مستقلة أو مسح باركود مباشر داخل شاشة الجرد.
- لا تعتمد محضر الجرد قبل التحقق من الكميات فعلياً وعمل نسخة احتياطية.
- تم فحص صياغة JavaScript وسلامة ZIP فقط؛ لم يتم اختبار شامل على متصفح حقيقي أو تدقيق محاسبي مستقل.

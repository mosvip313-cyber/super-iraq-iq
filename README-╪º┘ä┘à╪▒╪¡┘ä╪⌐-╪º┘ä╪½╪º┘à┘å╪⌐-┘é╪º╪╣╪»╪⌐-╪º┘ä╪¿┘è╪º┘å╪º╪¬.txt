سوبر العراق IQ — المرحلة الثامنة: قاعدة البيانات المحلية

ما الذي تغيّر؟
- إضافة IndexedDB كطبقة حفظ أساسية داخل المتصفح.
- عند أول تشغيل، يحاول البرنامج ترحيل البيانات الموجودة في localStorage إلى IndexedDB دون حذف بيانات النسخة القديمة.
- عند التشغيل، يقارن البرنامج وقت آخر تحديث ويختار النسخة الأحدث بين قاعدة البيانات والنسخة المحلية.
- يستمر تحديث localStorage كنسخة توافق احتياطية عند الإمكان.
- إضافة إظهار حالة التخزين ومعلومات الخطأ في صفحة «عن البرنامج».
- تحسين ملف النسخ الاحتياطي ليشمل معلومات إصدار التخزين، وتحديد حد 50 ميغابايت لملف الاستعادة.
- الحفاظ على الميزات الحالية: المبيعات، المنتجات، العملاء، إعدادات المتجر، الباركود، التقارير، تسجيل الدخول والتفعيل.

طريقة التشغيل
1. فك ضغط ZIP.
2. افتح apps/admin-web/index.html في متصفح حديث يدعم IndexedDB.
3. استخدم بيانات الدخول والتفعيل الحالية لهذا المتصفح؛ التفعيل والحساب لا ينتقلان تلقائياً إلى متصفح آخر.
4. من الإعدادات > النسخ الاحتياطي، نزّل نسخة JSON واحفظها في مكان آمن بشكل دوري.

حدود مهمة
- IndexedDB تحفظ البيانات داخل نفس ملف تعريف المتصفح/الجهاز، وليست قاعدة بيانات خادم أو SQLite.
- لا توجد مزامنة فعلية بين الأجهزة أو الفروع بعد.
- مسح بيانات المتصفح أو استخدام ملف تعريف/متصفح آخر قد يجعل البيانات غير متاحة؛ احتفظ بنسخة احتياطية خارجية.
- تم فحص صياغة JavaScript باستخدام node --check والتحقق من سلامة ZIP؛ لم يتوفر اختبار متصفح آلي ضمن بيئة البناء الحالية.

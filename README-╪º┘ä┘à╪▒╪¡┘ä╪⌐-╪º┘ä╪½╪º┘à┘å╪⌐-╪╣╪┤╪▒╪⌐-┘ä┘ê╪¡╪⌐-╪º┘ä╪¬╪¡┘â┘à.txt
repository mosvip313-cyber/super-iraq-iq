سوبر العراق IQ — المرحلة 18: لوحة التحكم والكاشير السريع

- لوحة رئيسية تعرض إجمالي مبيعات اليوم وعدد فواتيره ومتوسط الفاتورة والربح التقديري ومخزون المنتجات القليل.
- آخر 6 فواتير مسجلة وتنبيهات المنتجات التي مخزونها 5 قطع أو أقل.
- أزرار مختصرة للانتقال إلى البيع والمنتجات والعملاء والمحاسبة.
- الربح المعروض تقديري قبل المصاريف التشغيلية، ويظهر غير مكتمل إذا كانت تكلفة أي مادة مباعة غير محفوظة.
- بيانات اللوحة محلية وتعتمد على السجلات الموجودة في هذا الجهاز؛ لا تعني أن المزامنة السحابية مفعّلة.
- فحص صياغة JavaScript وسلامة الأرشيف تم؛ لم ينفذ اختبار متصفح شامل.

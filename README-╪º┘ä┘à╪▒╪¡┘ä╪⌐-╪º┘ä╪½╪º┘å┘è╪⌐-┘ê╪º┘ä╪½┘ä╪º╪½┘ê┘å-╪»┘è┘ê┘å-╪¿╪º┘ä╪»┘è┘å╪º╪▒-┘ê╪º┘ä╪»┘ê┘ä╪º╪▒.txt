سوبر العراق IQ — المرحلة 32: تحصيل الديون وتسديد الموردين بعملتين

التحديث:
- أضيف اختيار عملة التحصيل في قسم المحاسبة: دينار عراقي أو دولار أمريكي.
- أضيف اختيار عملة تسديد المورد: دينار عراقي أو دولار أمريكي.
- يحفظ كل دفع المبلغ الأصلي والعملة وسعر الصرف المسجل وقت العملية.
- تُخصم الدفعات من أرصدة الديون الدفترية بالدينار العراقي بعد تحويلها بسعر الصرف الحالي وقت الدفع.
- تسجل الخزنة القيمة الدفترية بالدينار مع amountOriginal وcurrency وexchangeRate، حتى يظهر مبلغ العملية بعملته الأصلية في سجل الحركات.

طريقة الاستخدام:
1. فك ضغط المشروع وشغله بالطريقة المعتادة.
2. افتح «المحاسبة والتحصيل والورديات».
3. اختر العميل أو المورد.
4. اختر عملة المبلغ، أدخل المبلغ، ثم سجل التحصيل أو التسديد.
5. راجع سعر صرف الدولار من إعدادات/سعر الصرف قبل التسجيل.

مهم:
- أرصدة العملاء والموردين القديمة تُحفظ بالدينار العراقي؛ هذه المرحلة لا تحول السجلات القديمة ولا تنشئ أرصدة مستقلة لكل عملة.
- الدفع بعملة مختلفة من عملة الفاتورة يحوّل بالقيمة الدفترية وفق سعر الصرف وقت التسديد؛ فروقات الصرف لا تُرحّل آلياً إلى حساب محاسبي مستقل.
- ما زال ربط القيود المحاسبية التلقائي والمزامنة الفعلية بين الأجهزة بحاجة إلى تطوير واختبار.
- تم فحص صياغة JavaScript وسلامة ملف ZIP، ولم يتم اختبار المرحلة على متجر إنتاج فعلي أو خادم سحابي منشور.

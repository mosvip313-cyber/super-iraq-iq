سوبر العراق IQ — إصلاح فتح واجهة المرحلة 16

المشكلة التي ظهرت: شاشة تفعيل البرنامج تظهر بدون الحقول والأزرار.

السبب: متغير قائمة مسودة فاتورة الشراء (purchaseDraftItems) كان يُستخدم عند تشغيل الأقسام ولم يكن معرّفاً؛ أدى ذلك إلى توقف تهيئة الواجهة قبل رسم نموذج التفعيل.

الإصلاح: تعريف المتغير عند تهيئة التطبيق، وإظهار شاشة التفعيل قبل تحميل بقية الأقسام، وإضافة معالجة خطأ تعرض رسالة مفهومة بدلاً من بقاء الشاشة فارغة.

طريقة التشغيل على Windows:
1. نزّل ملف ZIP الجديد.
2. اضغط بزر الفأرة الأيمن واختر Extract All / استخراج الكل. لا تفتح index.html من داخل WinRAR أو مسار Temp.
3. افتح المجلد المستخرج ثم شغّل تشغيل-سوبر-العراق.bat أو افتح apps\admin-web\index.html.
4. مفتاح التفعيل التجريبي: SIQ-MSM-2026-07713541234
5. أنشئ حساب مدير عند أول تشغيل.

ملاحظة: هذا إصلاح لتوقف تهيئة الواجهة. ما زالت النسخة محلية وتجريبية؛ لم يُنفذ اختبار شامل لكل وظائف البرنامج أو مزامنة السحابة.
